Import from Portainer

Reads each compose stack out of Portainer and writes it to a folder under {{.Data.Root}}. Nothing is redeployed: the running containers are picked up by project name, which stays exactly the Portainer stack name. You get a preview before anything is written.

Connect to Portainer's API

Credentials stay in memory for this import only. They are never written to disk, and a restart forgets them.

Offline, from Portainer's data folder

For when the API is unreachable or the password is lost. Reads compose/<id>/docker-compose.yml and maps each ID to its project through the running containers. Env vars are read from stack.env when Portainer left one, and otherwise offered as suggestions you confirm one by one.
